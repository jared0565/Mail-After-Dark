# Mail After Dark

A calm, utilitarian browser popup with an editorial heading. One site, one switch.

- Colour: charcoal #14181e, slate surface #1e252e, pale text #e8ede9, sage accent #b5dec4.
- Typography: local Georgia for the heading; Segoe UI/sans-serif for controls. No font requests.
- Layout: 344px popup, 25px outer padding, one bordered settings panel.
- Components: semantic switch with checked/disabled/focus states; polite live status; explicit errors.
- Motion: 160ms thumb movement, disabled for reduced-motion preferences.
